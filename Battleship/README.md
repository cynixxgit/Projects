#Battleship Game

A classic game implemented in Java. This project demonstrates object oriented programming concepts including class design, inheritance, encapsulation, and state management.

##Features
Grid & Board Management: Tracks player moves, ship placements, hits, and misses on a dynamic grid.
Object Oriented Ship Hierachy: Custom classes and subclasses to represent different ship types and their status.
Game Logic & State: Validates user inputs, track hits, and detects when a ship or the fleet is sunk.

##Tech Stack
Language: Java
Concepts: Object-Oriented Programming, Data Structures, Input Validation
