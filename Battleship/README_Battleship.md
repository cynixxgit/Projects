# Battleship Game

A classic command-line Battleship game implemented in Java. This project demonstrates core Object-Oriented Programming (OOP) concepts, including class design, inheritance, encapsulation, and game-state management.

## Features
* **Grid & Board Management:** Tracks player moves, ship placements, hits, and misses on a dynamic grid.
* **Object-Oriented Ship Hierarchy:** Custom classes and subclasses to represent different ship types and their status.
* **Game Logic & State:** Validates user inputs, tracks hits, and detects when a ship or the fleet is sunk.

## Tech Stack
* **Language:** Java
* **Concepts:** Object-Oriented Programming (OOP), Data Structures, Input Validation
